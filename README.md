# PokeCollection — JP Edition

A retro-styled collection tracker for the original Japanese Pokémon TCG sets. Track which cards you own across every set, with Gen 1 Game Boy sprites and a dark pixel-art interface.

> Currently covers the first four Japanese sets only: **Base Set, Jungle, Fossil, and Rocket**. More sets may be added in the future.

## Features

- 4 official Japanese sets with verified card lists (263 cards total)
- Gen 1 Game Boy sprites for all Pokémon cards
- Cards appear as silhouettes until marked as owned
- Holo Rare cards have an animated shimmer effect
- Filter by All / Owned / Missing
- Multilingual support: FR / EN / JP
- Search across all three languages simultaneously
- Progress bar and completion stats per set and globally
- Export / Import collection as JSON
- Works offline — single HTML file, no dependencies
- Ready for GitHub Pages

## Usage

Open `index.html` in any browser, or deploy to GitHub Pages. Click a card to toggle it as owned. Your collection is saved automatically in your browser's localStorage.
